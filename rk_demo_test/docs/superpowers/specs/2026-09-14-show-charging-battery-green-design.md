# 在站充电电池图标设计

## 目标

状态栏使用足浴 MCU 电量和最近有效 `LINK_STATUS` 判断电池图标颜色。当设备在站且电池图标尚未达到满格档时，将图标显示为绿色，直观表示正在充电。

## 显示规则

- 继续使用现有五档电池符号：0～4% 为空电池、5～19% 为一格、20～49% 为两格、50～79% 为三格、80～100% 为满格。
- `LINK_STATUS == 0x01` 且 MCU 电量低于 80% 时，电池图标显示绿色。
- MCU 电量达到 80～100% 的满格档时，电池图标保持白色，即使设备仍在站也不显示绿色。
- `LINK_STATUS == 0x00` 时，所有电量档位均显示白色。
- 尚未收到有效位置状态或 MCU 链路超时时，沿用最近有效位置和电量缓存；本功能不改变现有缓存与超时语义。

## 实现方式

复用状态栏现有一秒定时器，在 LVGL 线程内同时读取 MCU 电量缓存和最近有效 `LINK_STATUS`。电池图标更新函数继续负责选择五档符号，并在同一次刷新中设置白色或绿色，串口线程不直接操作 LVGL 对象。

颜色使用项目现有 LVGL 样式接口设置，集中定义充电绿色和普通白色，避免在业务代码中散落色值。页面切换不重建电量或充电状态，状态栏下一次定时刷新时自然反映最新状态。

## 边界与错误处理

- 79% 在站显示三格绿色，80% 在站显示满格白色。
- 电量从低于80%升至80%后，下一次状态栏刷新恢复白色。
- 在站状态切换为离站后，下一次状态栏刷新恢复白色。
- 非法 MCU 电量不更新缓存，因此不会单独改变图标档位或颜色。
- 本功能只改变状态栏电池图标颜色，不增加充电协议字段，不改变低电保护和按钮行为。

## 验证

静态核查 79/80% 边界、在站/离站切换、非法电量保留和页面切换路径。按项目要求执行 `make lvgl_demo-dirclean && make lvgl_demo-rebuild`；目标板上确认绿色、白色及刷新延迟符合预期。
