# 离站低电保护设计

## 目标

MCU有效电量低于20%且设备处于有效离站状态时，仅执行一次低电保护：在当前页面显示“电量过低”，复用 `system_bucket_stop()` 清空泡脚倒计时、温度和定时编辑、离站延迟启动、按摩、恒温、除菌及相关图标，并一次性下发A1。

## 触发规则

- `battery < 20 && LINK_STATUS == 0x00` 首次成立时触发。
- 在站、位置未知或通信超时时不提示、不停止，也不消费本轮触发资格。
- 在站期间已经低电，随后有效离站时触发。
- 持续低电只触发一次；触发后回站再离站不重复。
- 收到20%及以上的有效电量后重新武装。
- 非法BCD电量不更新缓存，也不改变武装状态。

## 模块边界

串口层继续负责合法帧校验、电量解析和原子缓存，并在电量或位置变化后请求业务层检查。`system_manager` 联合判断电量、MCU链路三态和最近有效位置，通过 `lv_async_call()` 把实际处理投递到LVGL线程。LVGL事务再次核对条件，锁存本轮已处理状态，调用统一停止入口后显示现有消息弹窗。

状态栏只负责显示电量，不承担低电业务。串口线程不直接操作LVGL对象。

## 验证

静态检查19/20%边界、位置与电量先后到达、重复帧、回站再离站、恢复重新武装、非法电量和通信超时路径。执行 `make lvgl_demo-dirclean && make lvgl_demo-rebuild`。目标板上验证弹窗、A1只发送一次以及泡脚状态清理；无设备时保留实测任务。
